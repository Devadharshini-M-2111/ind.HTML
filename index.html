Project Overview

This project models a city road network as a weighted, undirected graph. Parcels are sorted by priority—URGENT, HIGH, then NORMAL—and Dijkstra’s algorithm finds a shortest route from the Warehouse to each destination. Estimated time assumes a constant speed of 30 km/h.

Algorithm Workflow

  1. Represent each location as a vertex and each road as a weighted edge.
  2. Sort parcels by priority: URGENT → HIGH → NORMAL.
  3. Run Dijkstra’s algorithm from the Warehouse to the destination.
  4. Reconstruct the path using predecessor links.
  5. Estimate time: distance ÷ speed × 60.
  6. Display parcel routes and summary totals.

Dijkstra Pseudocode

DIJKSTRA(G, source, target)
  for each vertex v:
      dist[v] = infinity
  dist[source] = 0
  Q = min-heap with (0, source)

  while Q is not empty:
      (d, u) = extract-min(Q)
      if d != dist[u]: continue
      if u == target: break
      for each edge (u, v, w):
          if d + w < dist[v]:
              dist[v] = d + w
              prev[v] = u
              push(Q, (dist[v], v))

  return reconstructed path, dist[target]

Advantages

  • Finds optimal shortest paths for non-negative road distances.
  • Urgent parcels appear first in the dispatch queue.
  • Uses efficient graph structures and a min-heap.
  • Clear route and delivery-time summaries.

Limitations

  • Each parcel is routed independently from the Warehouse.
  • Agent assignment is hard-coded.
  • Vehicle capacity and deadlines are not checked.
  • Assumes fixed speed and ignores traffic and service time.
  • Sample network is small and illustrative.

Future Enhancements

01 · Smarter computation

Run Dijkstra once for all destinations; add Floyd–Warshall for repeated queries.

02 · Capacity & deadlines

Include parcel weights, vehicle capacity, deadlines and knapsack-based selection.

03 · Multi-stop routing

Assign parcels automatically and build agent tours with exact or approximation methods.

Conclusion

The project demonstrates priority-based parcel dispatch and Dijkstra shortest-path routing on a weighted graph. The sample results are 10 km to the Hospital, 15 km to Lake View, 6 km to North Street and 7 km to East Market. The report’s main next step is to combine individual routes into capacity- and deadline-aware multi-stop tours, a more complex vehicle-routing problem.
